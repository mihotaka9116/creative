Creative & Colorful ポートフォリオサイト
📋 プロジェクト概要
「忙しい一日の終わりに、一脚の肘掛け椅子を」というコンセプトで制作した、色彩豊かなオリジナルグッズのショップサイトです。
画家のマティスが追求した「安らぎ」をテーマに、視覚的な心地よさと滑らかな操作性を両立させたシングルページ・ウェブサイトを構築しました。

💡 技術的なこだわりと実装ポイント
1. JavaScriptによる動的な演出
テキスト・タイピングアニメーション: メインコピーを一文字ずつ span 要素に分解し、transition-delay を動的に設定することで、洗練された出現演出を実装しました。

スクロール監視（Intersection Observer）: ブラウザの標準APIを活用し、要素が画面内に入ったタイミングでクラスを付与する「フェードイン演出」を採用。ライブラリに頼らず、軽量でパフォーマンスの良い実装を心がけました。

スムーススクロールの高度化: ヘッダーが固定（position: fixed）されていることを考慮し、遷移先の位置からヘッダーの高さを自動計算してオフセットをかける調整を行っています。

2. ローカルストレージを活用したカート機能
データ永続化: localStorage を使用し、ブラウザを閉じてもカート情報（miho_cart_data）が保持される仕組みを構築しました。

リアルタイムUI更新: 商品追加時にバッジの数字を即座に更新し、「追加しました！」というフィードバックをボタンに表示させることで、直感的なUXを実現しています。

3. グラフィックとCSSアニメーション
SVGキーフレームアニメーション: Illustratorで作成したインラインSVGに対し、CSSで明滅アニメーション（window-glow）を付与。軽量ながら表情豊かなメインビジュアルを実現しました。

3段階のレスポンシブ設計: モバイル・タブレット・PCの各デバイスに最適化。特にモバイル環境では、ハンバーガーメニューへの切り替えや商品グリッドのレイアウト変更を行い、ユーザビリティを高めています。

📂 主なファイル構成
index.html: セマンティックなマークアップによる構造化

style.css: 変数管理（CSS Variables）と詳細なレスポンシブ定義

script.js: 各種インタラクションおよびカートシステムのロジック
